# covLW

## Ledoit-Wolf Covariance Matrix Estimators

[![GitHub R package
version](https://img.shields.io/github/r-package/v/Carol-seven/covLW?label=R%20in%20dev&color=green)](https://github.com/Carol-seven/covLW/blob/main/DESCRIPTION)
[![GitHub last
commit](https://img.shields.io/github/last-commit/Carol-seven/covLW)](https://github.com/Carol-seven/covLW/commits/main)
[![R-CMD-check](https://github.com/Carol-seven/covLW/actions/workflows/R-CMD-check.yaml/badge.svg)](https://github.com/Carol-seven/covLW/actions/workflows/R-CMD-check.yaml)
[![GitHub
License](https://img.shields.io/github/license/Carol-seven/covLW?color=blue)](https://github.com/Carol-seven/covLW/blob/main/LICENSE.md)

The goal of **covLW** is to provide a collection of statistical methods
that implement linear and nonlinear shrinkage estimators for
large-dimensional covariance matrices developed by
[Ledoit](http://www.ledoit.net/) and
[Wolf](https://www.econ.uzh.ch/en/people/faculty/wolf.html).

## Installation

You can install the development version of **covLW** from
[GitHub](https://github.com/Carol-seven/covLW) with:

``` R
# install.packages("pak")
pak::pak("Carol-seven/covLW")
```
